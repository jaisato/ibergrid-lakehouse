# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/jaisato/ibergrid-lakehouse/security/advisories/new)
rather than in a public issue. Include what is affected, how to reproduce it and its impact. You
should get an answer within a week.

## Supported versions

Only the latest release and `main` receive fixes.

## Practices in this repository

- Secrets live in a git-ignored `.env` (generated by `make env`) or in GitHub environment secrets,
  never in the repository; gitleaks scans every pull request's history and runs as a pre-commit
  hook.
- Third-party container images are pinned by digest and GitHub Actions by commit SHA; Dependabot
  proposes dependency and action updates monthly.
- Containers run as non-root users with `no-new-privileges`, all capabilities dropped and memory
  limits; no port is published in production, and locally only on 127.0.0.1.
- The catalog (Lakekeeper) runs without authentication in this phase, so it must not be exposed
  to untrusted networks. Public endpoints (phase 6) require authentication in front of it.
